# The Hausdorff Dimension of Limit Sets of Well-distributed Schottky Groups

Code, figures and thesis for the M.A. thesis of William Huanshan Chuang (San Francisco State University, May 2022; thesis chair Chun-Kit Lai).

## Problem

Let $G$ be a finitely generated Schottky group acting on the Poincaré disk $\mathbb{B}^2$. Finding the exact Hausdorff dimension of its limit set $L(G)$ when $L(G) \neq \partial\mathbb{B}^2$ is an open problem. The thesis proves bounds for one class of such groups and conjectures an exact value.

## Results

- **Definition.** A *well-distributed* Schottky group $\Gamma = \langle T_1, \dots, T_m \rangle$. Its orbit $\Gamma(0)$ is reconstructed from two operators $T$ and $R$ for every $m \in \mathbb{Z}^+$.
- **Theorem 4.7.** For a well-distributed Schottky group of order 2,

  $$\frac{\ln 2}{\ln \cosh r} \le \delta(\Gamma) \le \min\left\{\frac{\ln 4}{\ln \cosh r},\ 1\right\},$$

  where $\delta(\Gamma)$ is the critical exponent of the Poincaré series, which equals the Hausdorff dimension of $L(\Gamma)$ (Patterson–Sullivan), and $r$ is defined in Chapter 4.
- **Theorem 4.8.** Sharper bounds when $0 < \alpha \le \pi/4$, with $\alpha$ as defined in Chapter 4.
- **Conjecture.** $\delta(\Gamma) = \dfrac{\ln 3}{\ln \cosh r}$, compared in Chapters 5–6 against numerical values from McMullen's algorithm.

## Running the code

The notebooks need Python 3 with NumPy. Each file in `src_in_C/` is a Cython-generated Python extension module; build it with a C compiler that supports OpenMP against the Python development headers.
